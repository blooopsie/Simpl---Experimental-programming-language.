Note: If a variable is added into a list, the list receives the value of
that variable.

Note 2: Between two print commands is a new line character.

Note 3: The ASCII character in a memory cell equals its corresponding
value.

Note 4: Strings can also use single-quotes, as do docstrings.

Note 5: Variables can either be strings or integers or floats.

Note 6: Simpl is 0-indexed.

Note 7: The user input is always treated as a string.

Note 8: All functions compatible with strings are also compatible with
docstrings.

Note 9: Both strings and lists are iterables.

-   Identifier names can:
    -   have letters
    -   have numbers but not start with one
    -   not have spaces
    -   have underscores
    -   not be a keyword

-   Special characters:
    -   \n: Newline.
    -   \t: Tab.
    -   \\: Backslash.
    -   \": Double quotes.
    -   \0: Null.

-   Truthy and falsy:

  Truthy                        Falsy
  ----------------------------- -----------------
  Nonzero numbers (int/float)   0
  Nonempty iterables            Empty iterable
  Boolean "True"                Boolean "False"

Precedence

  Operator                   Description
  -------------------------- -------------------------------------------------------
  ()                         Parentheses
  **                         Exponentiation
  +x, -x, ~x                 Unary plus, unary minus, and bitwise NOT
  *, /, //, %                Multiplication, division, floor division, and modulus
  +, -                       Addition and subtraction
  >>, <<                     Bitwise left and right shifts
  &                          Bitwise AND
  ^                          Bitwise XOR
  |                          Bitwise OR
  >, <, ==, !=, >=, <=, in   Comparison and membership operators
  not                        Logical NOT
  and                        AND
  or                         OR

Operators at the same level are evaluated from left to right.

Functional paradigm (FP) programming

Lambda so that functions don't need to be attached to a name:

    lambda def args: func

map() inputs a list and a lambda function, then returns a list.

    map([1, 2, 3, 4, 5], lambda def x: x ** x) # Returns [1, 4, 27, 256, 3125]

filter() inputs a list and a lambda function that returns either True or
False, then returns the list of all the elements that returned True.
(order of the elements is unchanged)

    import module[str] as alias[s]
    filter(["Ava", "Bob", "Mary", "Daniel", "Patricia"], lambda def x: ord(s.firstalpha(x)) < 77) # Returns ["Ava", "Bob", "Daniel"]

Finding errors

This programming language has a try-catch-else method.

    try: 
        /* faulty code */
    catch errorname:
        /* code */
    else:
        /* else is optional for finding errors */

Empty errorname means catch activates for any error. You can use redo in
the method to re-execute the content inside try. An error can be raised:

    raise errorname

Modules

How to import modules

You can import modules using this:

    import module[modulename]

This:

    import module[modulename] as alias[aliasname]

Or this:

    from module[modulename] import item[itemname] as alias[aliasname]

To import all attributes using from module[] import item[], do this:

    from module[modulename] import item[*]

Here’s the difference:

    import module[modulename]
    modulename.modulefunc()

    from module[modulename] import item[*]
    modulefunc()

Module 2: Turtle

The turtle module allows the use of a turtle to draw objects. It has
these commands and objects:

  Command                                                     Meaning
  ----------------------------------------------------------- --------------------------------------------------
  turtle.turnleft(n)                                          Turns the turtle left by n degrees.
  turtle.turnright(n)                                         Turns the turtle right by n degrees.
  turtle.forw(n)                                              Moves the turtle forward by n pixels.
  turtle.backw(n)                                             Moves the turtle backward by n pixels.
  turtle t = turtle.turtle()                                  Makes a turtle object.
  turtle t = turtle.screen()                                  Makes a screen object.
  turtle.color(rgb(a, b, c))                                  Sets the color of a turtle object.
  turtle.screencolor(color.rgb(a, b, c)/color.hsv(a, b, c))   Sets the color of a screen object.
  turtle.changex(n)                                           Changes the turtle's x coordinate by n pixels.
  turtle.changey(n)                                           Changes the turtle's y coordinate by n pixels.
  turtle.hide()                                               Hides all the turtles.
  turtle.clone()                                              A clone of a turtle.
  turtle.allturtle.[blah blah blah]()                         Makes all turtles move the same way.
  turtle.final()                                              Keeps the drawing even after the turtle is done.

Example code that makes a 20px by 20px square on the turtle screen:

    import module[turtle] as alias[t]
    turtle n = t.turtle()
    loop 4:
        n.forw(20)
        n.turnleft(90)
    n.final()

Codegolfing

Conditionals with 1 branch

    check if condition: (/Code/)

Conditionals with 2 branches

    check if condition: (/*Code*/) else: (/*Code*/)

Match statements:

    match element: if obj1: (/*code*/) /*if obj2: (/*code*/)...*/

Multiple commands in one line:

    cmd1; /cmd2; cmd3;.../

Ternary operator:

    var_name = (cond) ? yes: (/*value1*/) no: (/*value2*/)

Or this:

    (cond) ? yes: (/*code*/) no: (/*code*/)
